# CoffeeShopSystem_DasarPemograman
Coffee shop system in C++ (CLI) | Sistem coffee shop berbasis C++ dengan antarmuka CLI: kelola stok &amp; menu (admin), pesan, bayar, dan cetak struk (pembeli).

## Features

**Admin**
- Stock in / stock out
- Check stock
- Menu and price list

**Customer**
- Enter customer name
- Browse the menu
- Order items with quantity
- Payment input
- Printed receipt (customer name, items, quantity, total price, change)

## Tech

- Language: C++
- Interface: CLI (console only)
- Data storage: plain text files
